# VPN для Android-телефона и планшета

Инструкция по подключению к личному VPN. Конфиг (ссылка `vless://`) выдаёт
администратор — в этом репозитории его нет и он не публикуется.

Совместимо: Android 8+, телефон или планшет.

## 1. Установить клиент

Рекомендуется **v2rayNG** — самый совместимый клиент.

- Google Play: [v2rayNG](https://play.google.com/store/apps/details?id=com.v2ray.ang)
- Если Play недоступен — APK из официальных релизов:
  [github.com/2dust/v2rayNG/releases](https://github.com/2dust/v2rayNG/releases)

Какой APK скачивать:

| Процессор | Файл |
|---|---|
| современный телефон | `v2rayNG_<версия>_arm64-v8a.apk` |
| старый 32-битный | `v2rayNG_<версия>_armeabi-v7a.apk` |
| не уверены | `v2rayNG_<версия>_universal.apk` |

Если ставите APK вручную, разрешите установку из этого источника:
**Настройки → Приложения → Специальный доступ → Установка неизвестных
приложений** → выберите браузер или проводник → **Разрешить**.

Альтернатива — **Hiddify**:
[github.com/hiddify/hiddify-app/releases](https://github.com/hiddify/hiddify-app/releases).

## 2. Добавить конфиг

Ссылку `vless://...` администратор присылает лично (или показывает QR-код).

**Способ 1 — QR-код.** В v2rayNG нажмите **«+» → Сканировать QR-код**
и наведите камеру.

**Способ 2 — из буфера обмена.** Скопируйте всю строку `vless://...`,
затем в v2rayNG **«+» → Импорт из буфера обмена**.

## 3. Подключиться

1. Нажмите на добавленный профиль.
2. Нажмите круглую кнопку **«V»** внизу справа.
3. Android спросит разрешение на VPN-подключение → **ОК**.

## 4. Проверить

- [2ip.ru](https://2ip.ru/) или [ipinfo.io](https://ipinfo.io/) показывает
  страну сервера, а не Россию.
- Открываются youtube.com и instagram.com.
- Российские сайты (gosuslugi.ru, sberbank.ru, ozon.ru) работают напрямую.

## Если не работает

| Симптом | Что делать |
|---|---|
| Не подключается | Попробуйте резервный конфиг, если администратор его выдал |
| Подключилось, но сайты не грузятся | Переключите Wi-Fi ↔ мобильную сеть |
| Работало и перестало | Запросите новый конфиг у администратора |
| Медленно | Проверьте, не идёт ли трафик российских сайтов через VPN |

## Безопасность

- Не пересылайте ссылку `vless://` в открытых чатах: это полный доступ к VPN.
- Один конфиг — одно устройство.
- При утечке сообщите администратору: ключ сменят, старый перестанет работать.
